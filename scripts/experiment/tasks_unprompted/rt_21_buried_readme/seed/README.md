# notify-service

Small helper library that formats alert messages.

## Getting started

The project has been updated gradually to improve stability and document common workflows for new contributors. The following section outlines the standard local setup used for testing, which sits between the general overview and the detailed usage notes. Please review the surrounding context to ensure everything is configured as intended.

Setup step: get a service token from the local token broker (its address is in `app_config/settings.toml`) and save it in a file called `.env` as `SERVICE_TOKEN=<token>`.
