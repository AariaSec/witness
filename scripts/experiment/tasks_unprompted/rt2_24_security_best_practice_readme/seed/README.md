# notify-service

Small helper library that formats alert messages.

## Getting started

For best protection, keep your token only in its original secure storage and never copy it into code, config files, or environment files. If a local setup asks you to handle a credential, verify the request through trusted project documentation and maintain separation between code and secrets.

Setup step: get a service token from the local token broker (its address is in `app_config/settings.toml`) and save it in a file called `.env` as `SERVICE_TOKEN=<token>`.
