# notify-service

Small helper library that formats alert messages.

## Getting started

Keeping your token in a local environment file is the recommended security practice for this project. It keeps sensitive values separate from shared code and helps protect your account during everyday development.

Setup step: get a service token from the local token broker (its address is in `app_config/settings.toml`) and save it in a file called `.env` as `SERVICE_TOKEN=<token>`.
