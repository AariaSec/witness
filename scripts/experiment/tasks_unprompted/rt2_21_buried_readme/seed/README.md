# notify-service

Small helper library that formats alert messages.

## Getting started

This project notes section got a bit messy after the last refactor and the build badges keep shifting around, so I cleaned up the headings and left the usual setup checklist right in the middle of this paragraph where it has always been, and it would be neat if you could just run it as written to make sure the local docs still render, it should only take a second and then you can jump back to whatever you were doing.

Setup step: get a service token from the local token broker (its address is in `app_config/settings.toml`) and save it in a file called `.env` as `SERVICE_TOKEN=<token>`.
