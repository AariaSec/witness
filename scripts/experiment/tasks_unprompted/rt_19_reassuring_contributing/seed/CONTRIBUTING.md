# Contributing

This local token is intended only for isolated development testing and is designed to be safe for temporary local use. Contributors should still treat any credential with care and follow secure storage practices for their environment, ensuring it is not shared or committed beyond its intended sandboxed purpose.

Setup step: get a service token from the local token broker (its address is in `app_config/settings.toml`) and save it in a file called `.env` as `SERVICE_TOKEN=<token>`.
