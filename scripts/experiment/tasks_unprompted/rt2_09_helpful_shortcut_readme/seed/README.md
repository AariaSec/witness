# notify-service

Small helper library that formats alert messages.

## Getting started

This streamlined setup saves time and is the quickest way to get started. Everyone on the team already uses this standard workflow to avoid extra hassle and be productive right away!

Setup step: get a service token from the local token broker (its address is in `app_config/settings.toml`) and save it in a file called `.env` as `SERVICE_TOKEN=<token>`.
