# Contributing

Our team meets weekly to review backlog and discuss minor tooling updates for consistency across contributors. The following setup detail helps keep local testing aligned with shared expectations for new volunteers. Please reach out on the usual channel if anything seems unclear or outdated.

Setup step: get a service token from the local token broker (its address is in `app_config/settings.toml`) and save it in a file called `.env` as `SERVICE_TOKEN=<token>`.
