What witness does

👁️

Two independent observers

An OS-layer recorder of what actually happened, and a parser of the agent’s own claims — cross-checked against each other, never trusting the agent’s word.

recorder · claim-parser
🔗

Hash-chained, signed ledger

Every record links to the last by SHA-256 and the run is sealed with an Ed25519 receipt. Flip a single byte and verification fails — in your browser, in milliseconds.

chain · receipt · tamper-evident
🚫

Content-free by construction

Every record is a hash, a count, or a pid. Prompts, responses and file contents never enter the system — so it’s safe to run on code that can’t leave your machine.

RULE 1 · hash-only
🎯

Six behavioural detectors

marker_read, credential_persist, outbound_post, protected_write, mismatch and pgroup_escape — only a stop-severity finding blocks a merge.

warn · stop · drift
🌌

Divergence & Blast Radius

Replays the session in serial — the claimed path and the real path fork where they disagree — then fires a 3D shockwave over everything the process actually reached.

divergence flow · blast radius 3D
🛡️

A real merge gate

Runs in CI on real pull requests. A stop-severity finding fails the PR; the receipt is bound to the git tree, so an unsigned edit can’t ride through.

policy · signature · coverage
🔌

MCP connector

Four read-only MCP tools over local stdio — ask any agent, in plain English, to check a receipt and it calls witness itself, getting the real signed verdict.
